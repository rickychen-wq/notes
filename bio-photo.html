小單元一

ATP 的介紹與結構

細胞的能量貨幣

一、ATP 是什麼

ATP ＝ 三磷酸腺苷（腺嘌呤核苷三磷酸）

  • 是一種 核苷酸
  • 組成三部分：核糖＋腺嘌呤＋三個磷酸根
是核糖不是去氧核糖。所以 ATP 可以當 RNA 的原料，不是 DNA。

命名系統（看名字就知道結構）

字代表種類
核五碳糖核糖／去氧核糖（去氧會標 d-）
苷含氮鹼基A、G、C、T、U
酸磷酸根1～3 個 → MP／DP／TP

所以 A-TP ＝ 腺嘌呤（A）＋ 三個（Tri）磷酸。同理 AMP 是一個、ADP 是兩個。

ATP 的兩個功能

  • 聚合形成 RNA（核糖核酸） 的原料之一
  • 細胞活動時能量的直接供應者 ＝ 能量貨幣

二、高能磷酸鍵

分子磷酸根數高能磷酸鍵數
ATP 三磷酸腺苷32 個
ADP 二磷酸腺苷21 個
AMP 單磷酸腺苷10 個（不具高能磷酸鍵）

高能磷酸鍵是磷酸根與磷酸根之間的鍵；AMP 只有一個磷酸根接在核糖上，所以沒有。

「高能磷酸鍵釋放能量」的真相

這個名稱是早期科學家取的，因為觀察到鍵結水解時整體會釋出能量。但正確理解是：

打斷鍵結本身是耗能的。之所以整體釋能，是因為斷裂後與水化合形成的產物比原來更穩定（跟電荷排斥、共振有關），前後能量差才是釋出的能量。

ATP ⇌ ADP 的循環

ADP ＋ Pi　——磷酸化（脫水）——▶　ATP　　需要提供能量
ATP　——水解——▶　ADP ＋ Pi　　能量釋出

一個分子接受磷酸根的反應就叫 磷酸化。

一、化學滲透磷酸化

電子傳遞鏈長在哪

由膜上一系列電子載體構成，三個位置要記：

  • 細菌 → 細胞膜
  • 粒線體 → 內膜
  • 葉綠體 → 類囊體膜

電子為什麼會一直往下傳

  • 各電子載體對電子的親和力依序增加，所以電子會依序被往下移交
    親和力：載體 A ＜ B ＜ C
  • 電子每傳一次就釋出一部分能量
    電子能量：A ＞ B ＞ C
  • 釋出能量後的電子離開傳遞鏈，最後被別的分子接收
常考的觀念題：電子傳遞鏈中傳遞的電子，最後不會成為 ATP 分子的一部分。它只是負責「一路放能」，能量拿去打 H⁺ 過膜而已。

H⁺ 怎麼變成 ATP

① 電子傳遞釋出的能量，把 H⁺ 跨膜打到膜的另一側
② 膜兩側形成 H⁺ 濃度梯度
③ H⁺ 想順著濃度往回擴散，但帶電無法穿過脂雙層
④ 只能走膜上的 H⁺ 通道蛋白 —— 而 ATP 合成酶本身就是 H⁺ 通道蛋白
⑤ H⁺ 衝過去時激活酵素 → ADP ＋ Pi 合成 ATP

有些電子載體同時具有氫離子幫浦的作用，就是負責第①步的。

二、受質階層磷酸化

酵素的受質藉由酵素催化，把自己所含的磷酸基與能量一起轉移給 ADP 而生成 ATP。

例：糖解作用中，丙酮酸激酶催化
PEP（受質 A）＋ ADP（受質 B）→ 丙酮酸 ＋ ATP

磷酸根 (Pi) 透過酵素催化，由受質 A 轉移至受質 B。全程沒有電子傳遞鏈參與。

其他能量流通分子

三種輔酶

NADPH ／ NADH ／ FADH₂

它們在做什麼

是 H⁺ 與高能電子的攜帶者，也就是參與氧化還原反應的輔酶。

小複習　氧化 ＝ 失電子　　還原 ＝ 得電子

三種輔酶對照

氧化態還原態參與的作用
NADP⁺NADPH光合作用
NAD⁺NADH呼吸作用
FADFADH₂呼吸作用

結構共同點：都屬於核苷酸類、成分中含特定的維生素 B。

分辨法：名字裡有 P 的（NADP）走光合作用，沒有 P 的（NAD、FAD）走呼吸作用。

三個互換反應式（要會默寫）

NADP⁺ ＋ 2e⁻ ＋ H⁺ ⇌ NADPH
NAD⁺ ＋ 2e⁻ ＋ H⁺ ⇌ NADH
FAD ＋ 2e⁻ ＋ 2H⁺ ⇌ FADH₂
兩個容易寫錯的地方：
① FAD 不帶電，不要寫成 FAD⁺
② FADH₂ 收兩個 H⁺，另外兩個只收一個 H⁺

為什麼 NADPH 是高能物質

  • NADP⁺ 和高能電子與 H⁺ 結合後形成還原態的 NADPH
  • NADPH 帶有高能電子，所以是高能物質
  • 但它跟高能電子的親和力並不好，很容易在反應中把電子丟給別人
講義那格填「氧化性」是錯的。把電子丟給別人的是還原劑，所以 NADPH 具有很強的 還原力（還原性）。它讓別人被還原，自己被氧化。
對照定義：氧化＝失電子。NADPH 失去電子 → 它自己被氧化 → 它是還原劑。
光合作用

光反應

光體系 ／ 兩種電子流 ／ 光水解

一、先搞懂光合作用在幹嘛

  • 目的：製造有機養分，直接產物是醣類；碳元素來自 CO₂
  • 由 CO₂ 合成醣類的反應叫 同化作用，兩個特點：
    • 是合成反應 → 需要能量 → 由 ATP 提供
    • 是還原反應 → 需要電子 → 由 NADPH 提供
光反應吸收光能，轉變成細胞可利用的化學能（存在 ATP、NADPH 中）
碳反應利用前一階段的 ATP 與 NADPH，把 CO₂ 合成醣類

二、光體系（PS）

捕捉光能的流程

天線色素吸收光能 → 能量在色素分子間轉移 → 最後全部集中到反應中心
→ 反應中心的葉綠素電子被激發成高能激動態 → 釋出高能電子 → 進入電子傳遞鏈（或被電子載體接走）

天線色素只負責收集能量、不放電子；真正放出電子的是反應中心。

光體系 I（PSI）光體系 II（PSII）
天線色素葉綠素 a、葉綠素 b、胡蘿蔔素葉綠素 a、b、葉黃素
反應中心P700
（700 nm 有最大吸光度）		P680
（680 nm 有最大吸光度）

兩者的反應中心都是葉綠素 a，只是吸光度不同。P 後面的數字就是最大吸收波長。

三、兩種電子流（最常考）

循環式電子流（PSI 單獨作用）

PSI 各色素吸收能量 → 能量轉移至 P700 → P700 釋出電子
→ 電子經過電子傳遞鏈（過程中合成 ATP）
→ 電子最後又回到 PSI

目的：只產生 ATP（不產生 NADPH，也不放氧氣）

非循環式電子流（PSI 與 PSII 協同）

PSII 各色素吸收光能 → 轉移至 P680 → P680 釋出電子
→ 經過電子傳遞鏈（過程中合成 ATP）→ 電子轉移至 PSI
→ PSI 色素吸收能量 → 轉移至 P700 → P700 釋出電子
→ 經過少數電子載體後傳給 NADP⁺
→ NADP⁺（氧化態）吸收電子和 H⁺ 後合成 NADPH（還原態）

最後的電子接受者是 NADP⁺，接受後形成 NADPH。

目的：生成 ATP 和 NADPH

電子一去不回，所以 PSII 缺的電子必須另外補 → 這就是下面的光水解。

四、光水解作用

在非循環式電子流中，PSII 丟出的電子不會回來，所以植物在光反應一開始就用光能分解水當電子來源。

發生於 PSII　　H₂O → 2H⁺ ＋ 2e⁻ ＋ ½O₂

三個產物的去處：

  • O₂ → 離開葉綠體，被釋放到外界（對植物來說是廢物）
  • e⁻ → 被 PSII 的葉綠素 a（P680） 吸收，補充它受光激活後失去的電子
  • H⁺ → 留在類囊體內腔，順便增加濃度梯度
氧氣是水分解來的，不是 CO₂ 來的。這是課本一定會考的觀念。
