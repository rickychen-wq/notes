物質的特性與鑑定

物理性質鑑定 ＋ 化學性質鑑定

重點一　物理性質的鑑定方法

熔點（凝固點）

適用於常溫常壓下為固體的物質。

  • 分辨純物質與混合物：熔點固定＝純物質；不固定（一段範圍）＝混合物
  • 分辨純物質種類：熔點低＝分子物質；熔點高＝離子化合物或共價網狀晶體
  • 判斷同分異構物是否存在

例：可可鹼 357°C／茶鹼 273°C，兩者分子式同為 C7H8N4O2，是同分異構物。

沸點（凝結點）

適用於常溫常壓下為液體的物質，用途與熔點相同。

例：正丁醇 117.7°C／乙醚 34.6°C，分子式都是 C4H10O。

為什麼差這麼多正丁醇有 −OH 可形成氫鍵，乙醚沒有，所以沸點高很多。這是最愛考的延伸問法。

溶解度

相同溫度下，外觀相似的物質可能因結構不同而有不同溶解度。

  • 有機物：茶鹼可溶於水、可可鹼難溶；乙醇可溶、乙烷難溶
  • 無機物：氯化鈉 NaCl 可溶、氯化銀 AgCl 難溶

薄層層析法 TLC

利用不同物質對固定相附著力的差異，使物質在固定相上展開而分離。

Rf ＝ 物質的移動距離 (Y) ÷ 展開液的移動距離 (X)
  • 固定相與展開液不變時，同一物質的 Rf 值相同 → 可與標準品對照做鑑定
  • Rf 一定介於 0～1 之間
  • 應用：鑑定市售止痛藥成分（乙醯胺酚、布洛芬、阿司匹靈、咖啡因）

觀念澄正（1-1）

1. 純物質的加熱與冷卻曲線如圖所示（有水平段）
○ 正確　純物質在熔化或沸騰時溫度不變，所以會出現水平段；混合物則沒有明顯水平段，溫度會持續變化。
2. 層析法的樣品起始線應在展開液的液面上方
○ 正確　起始線若泡進展開液裡，樣品會直接溶入液體而不是被帶著展開，實驗就失敗了。
3. 層析法分離出的色素（或物質）必為純物質
✗ 錯誤　Rf 值相近的物質會跑在一起，同一個色點仍可能是混合物，要換展開液再測才能確認。
4. 層析法使用的展開液一定是水溶液
✗ 錯誤　展開液依樣品極性選擇，常用乙醇、丙酮、正己烷等有機溶劑或混合溶劑。

重點二　化學性質的鑑定：酸鹼性

已知指示劑變色範圍 a～b（a<b）：pH < a 顯酸型色，pH > b 顯鹼型色，介於 a～b 之間為兩者的混合色。

指示劑酸型色鹼型色變色範圍
石蕊紅藍4.5～8.3（中間紫）
溴瑞香草酚藍
BTB		黃藍6.0～7.6（中間綠）
酚酞無色紅8.2～10.0

大考常考用化學反應鑑定

①測有沒有碳酸根／碳酸氫根：加酸性試劑（鹽酸、硫酸），看有沒有冒二氧化碳。

CO32− ＋ 2H+ → CO2↑ ＋ H2O
HCO3− ＋ H+ → CO2↑ ＋ H2O

②測有沒有銨根：加強鹼試劑（NaOH 氫氧化鈉、Ca(OH)2 氫氧化鈣），看有沒有產生刺激臭味的氨氣。

NH4+ ＋ OH− → NH3↑ ＋ H2O

重點二　離子沉澱反應

兩種電解質溶液混合，若陰、陽離子結合成溶解度低的化合物，就會析出形成沉澱。

以無色 AgNO3（硝酸銀）＋ 無色 NaCl（氯化鈉）→ 白色 AgCl（氯化銀）沉澱為例，三種寫法：

❶ 全反應式（全部寫成化合物）
AgNO3(aq) ＋ NaCl(aq) → AgCl(s) ＋ NaNO3(aq)
❷ 離子反應式（強電解質拆成離子；弱電解質與沉澱寫化合物）
Ag+ ＋ NO3− ＋ Na+ ＋ Cl− → AgCl(s) ＋ Na+ ＋ NO3−
❸ 淨離子反應式（消去旁觀離子）
Ag+(aq) ＋ Cl−(aq) → AgCl(s)

旁觀離子反應前後沒變的離子（這裡是 Na+ 與 NO3−），要消掉。

混合液的分離

原則：一次只產生一種沉澱，所以加入的試劑必須「只跟其中一個離子形成沉澱，跟其他離子都可溶」。這就是為什麼試劑常挑 NO3−（硝酸根）或 Na+（鈉）當搭配離子 —— 它們永遠可溶，不會亂沉澱。

陽離子分離　Pb2+（鉛）、Ba2+（鋇）、Cu2+（銅）

加 NaCl → PbCl2↓（氯化鉛，白）
再加 Na2SO4 → BaSO4↓（硫酸鋇，白）
再加 Na2S → CuS↓（硫化銅，黑）

陰離子分離　Cl−（氯）、SO42−（硫酸根）、OH−（氫氧根）

加 Ba(NO3)2 → BaSO4↓（白）
再加 Mg(NO3)2 → Mg(OH)2↓（氫氧化鎂，白）
再加 AgNO3 → AgCl↓（白）

順序不能亂若先加 AgNO3，AgCl 跟 Ag2SO4 會一起沉，就分不開了。

反應式的平衡與化學計量

平衡 ／ 計量 ／ 限量試劑 ／ 反應分類

重點一　化學反應式與係數平衡

反應式代表的意義

  • 反應物與生成物的種類
  • 反應條件（催化劑、溫度、壓力、加熱、電解等）標在箭號上下方
  • 狀態標在化學式右側：(g) 氣態、(l) 液態、(s) 固態、(aq) 水溶液
  • 生成氣體加「↑」，生成沉澱加「↓」

平衡的兩大原理

①原子不滅：反應前後原子種類與數目不變。
②電荷不滅：反應前後總電荷量不變。

觀察法

把最複雜（原子數或種類最多）的物質係數訂為 1，或從兩邊各只出現一次的原子著手，其餘依原子不滅、電荷不滅決定。

H2O2 ＋ 2I− ＋ 2H+ → 2H2O ＋ I2

順序：訂 H2O2＝1 → 平 O → 平 H → 平電荷 → 平 I。

代數法

複雜物質訂 1，其餘設未知數，依原子不滅與電荷不滅列式再解；未知數愈少愈好，能用觀察法先定的就先定。

1MnO4− ＋ aC2O42− ＋ 2bH+ → 1Mn2+ ＋ 2aCO2 ＋ bH2O
O：4＋4a ＝ 4a＋b　　電荷：−1−2a＋2b ＝ +2
⇒ a ＝ 5/2、b ＝ 4　　係數 ×2 →
2MnO4− ＋ 5C2O42− ＋ 16H+ → 2Mn2+ ＋ 10CO2 ＋ 8H2O

觀念澄正（平衡）

1. 反應式平衡係數後，兩邊的分子數個數相等
✗ 錯誤　平衡保證的是原子數目相等，分子（粒子）總數常常不等。例：2H2＋O2→2H2O，左邊 3 個分子、右邊 2 個。
2. 化學反應式可用來預測生成物的種類
✗ 錯誤　反應式是把實驗觀察到的結果記錄下來，不是拿來預測會生成什麼。

延伸補充　氧化數與氧化數法平衡

氧化數判定通則

  • 元素態的氧化數為 0（Na、O2 中的兩個 O 都是 0）
  • 單原子離子＝所帶電荷（Mg2+ 為 +2、Cl− 為 −1）
  • 化合物中所有原子氧化數總和為 0
  • 多原子離子中總和＝離子電荷（SO42− 中 S 與 4 個 O 總和為 −2）

判斷順序IA＝+1、IIA＝+2、Al＝+3、F＝−1 ⇒ H＝+1（最常見）⇒ O＝−2（最常見）⇒ 鹵素＝−1（最常見）⇒ 其他元素最後推。

元素氧化數情況例
H+1非金屬氫化物（最常見）H2O
H−1金屬氫化物（與 IA、IIA 化合）CaH2
O−2最常見H2O
O−1過氧化物H2O2 過氧化氫
O−½超氧化物KO2 超氧化鉀
O+2只出現在與 F 的化合物OF2
鹵素−1最常見HCl 中 Cl
鹵素可變與上列元素結合時要配合變化HClO4 中 Cl 為 +7

氧化數法平衡（5 步驟）

以 MnO4−（過錳酸根）在酸性溶液中與 C2O42−（草酸根）反應為例：

  • Step1 寫出反應物與產物　MnO4−＋C2O42−→Mn2+＋CO2
  • Step2 列出氧化數有變動的元素，平衡該元素原子數，算氧化數改變量（Mn：+7→+2 減 5；C：+3→+4 每個增 1，兩個共 +2）
  • Step3 用最小公倍數使得失電子數相等 → Mn 乘 2、草酸根乘 5
  • Step4 平衡電荷：酸性用 H+、鹼性用 OH−
  • Step5 用 H2O 平衡 H、O 原子數
2MnO4−(aq) ＋ 5C2O42−(aq) ＋ 16H+(aq)
→ 2Mn2+(aq) ＋ 10CO2(g) ＋ 8H2O(l)

重點二　化學計量

利用已平衡的反應式，討論反應物與生成物之間莫耳數、質量或體積的關係。

莫耳數 ＝ 質量(g) ÷ 分(原)子量
＝ 粒子數 ÷ (6.02×1023)
＝ 氣體體積(L) ÷ 22.4　（0°C、1 atm）
＝ 氣體體積(L) ÷ 24.5　（25°C、1 atm）
＝ 體積莫耳濃度(M) × 體積(L)

解題流程已知量 → 換成莫耳數 → 用平衡係數換成待求物的莫耳數 → 再換成質量／體積／粒子數。中間一定要經過莫耳數，不能直接用質量比。

觀念澄正（計量）

1. 化學反應式的係數比就是反應物與生成物的莫耳數比
✗ 錯誤　係數比是反應掉與生成的莫耳數比，不是容器裡實際存在的莫耳數比（一開始加多少是自己決定的）。
2. 氣體的莫耳體積與溫度、壓力有關
○ 正確　所以 0°C、1 atm 是 22.4 L/mol，25°C、1 atm 變成 24.5 L/mol。看到體積換算一定要先確認溫壓。

重點三　限量試劑與產率

限量試劑

反應過程中完全耗盡的反應物，決定生成物的理論產量。

判斷法：比較各反應物的　莫耳數 ÷ 係數，最小者即為限量試劑

例　48 g N2H4（聯胺，分子量 32）與 92 g N2O4（分子量 92）完全反應：

2N2H4(g) ＋ N2O4(g) → 3N2(g) ＋ 4H2O(g)
N2H4：1.5 mol ÷ 2 ＝ 0.75　←較小，限量
N2O4：1 mol ÷ 1 ＝ 1
初　1.5　　1　　0　　0
中　−1.5　−0.75　+2.25　+3
末　0　　0.25　2.25　3
N2：2.25 mol × 28 ＝ 63 g

三行表初、中、末三行是最不會算錯的寫法，「中」那行的數字比一定等於係數比。

產率

產率（產量百分率）＝ 實際產量 ÷ 理論產量 × 100%

承上例，理論 63 g，實際只得 42 g → 產率 ＝ 42/63 × 100% ≒ 67%。

觀念澄正：限量試劑一定是反應物中莫耳數最少者
✗ 錯誤　要比的是莫耳數÷係數。莫耳數多但係數更大的，照樣可能先用完。

類型通式實例

反應熱的種類與性質

熱含量 ／ 熱化學方程式 ／ 燃燒熱與生成熱 ／ 赫斯定律

重點一　反應熱與熱化學方程式

熱含量 H（焓）

定溫定壓下，存在於物質本身的能量。

  • 無法直接測得，只能測「變化量」ΔH —— 這是最愛考的觀念
  • 受溫度、壓力、狀態及莫耳數（量）影響
  • 同一物質：氣態 > 液態 > 固態（位能差異）

反應熱 ΔH

ΔH ＝ 生成物熱含量總和 − 反應物熱含量總和
吸熱反應放熱反應
ΔHΔH > 0ΔH < 0
能量生成物 > 反應物反應物 > 生成物
周圍環境溫度下降溫度上升

標準反應熱 ΔH°：25°C、1 atm 下測得。未特別指明時，一般的 ΔH 即視為 ΔH°。（1982 年 IUPAC 把標準壓力改為 1 bar ≈ 0.987 atm，課本仍用 1 atm。）

影響 ΔH 的因素

①物質狀態

H2(g)＋½O2(g)→H2O(g)　ΔH＝−241.8 kJ
H2(g)＋½O2(g)→H2O(l)　ΔH＝−285.8 kJ

生成液態放出的熱較多，差的 44 kJ 就是水氣凝結放出的熱。

②反應物的莫耳數：係數變 n 倍，ΔH 也變 n 倍。

③單位：千焦耳 kJ、千卡 kcal，1 kcal ≈ 4.18 kJ。

熱化學方程式

加註物質狀態與反應熱的化學反應式。兩種寫法：

吸熱　N2(g)＋O2(g)→2NO(g)　ΔH＝+180.6 kJ
＝ N2(g)＋O2(g)＋180.6 kJ → 2NO(g)　（熱寫在左邊）
放熱　CH4(g)＋2O2(g)→CO2(g)＋2H2O(l)　ΔH＝−890.2 kJ
＝ CH4(g)＋2O2(g)→CO2(g)＋2H2O(l)＋890.2 kJ　（熱寫在右邊）

為什麼把熱當成一種「反應物／產物」看：吸熱是反應需要吸收能量，熱寫在左邊；放熱是反應放出能量，熱寫在右邊。

反應熱與係數的關係

  • 係數變 n 倍 → ΔH 也變 n 倍
  • 反應逆向進行 → ΔH 等值異號
H2(g)＋½O2(g)→H2O(g)　ΔH＝−241.8 kJ
H2O(g)→H2(g)＋½O2(g)　ΔH＝+241.8 kJ
觀念澄正：物質所具有的熱含量可由實驗測得
✗ 錯誤　熱含量的絕對值無法測得，實驗只能測出反應前後的變化量 ΔH。

重點二　燃燒熱與生成熱

莫耳燃燒熱莫耳生成熱
意義1 mol 物質完全燃燒時的反應熱1 mol 物質由其最穩定的成分元素生成時的反應熱
吸放熱必為放熱（ΔH<0）可能吸熱也可能放熱
零值不可燃物質（O2、H2O、CO2）燃燒熱為 025°C、1 atm 下以最穩定狀態存在的元素，生成熱為 0
係數為 1 的是被燒的反應物生成的產物
寫法1CH4(g)＋2O2(g)→CO2(g)＋2H2O(l)
ΔH＝−890.2 kJ		C(s)＋2H2(g)→1CH4(g)
ΔH＝−75 kJ

生成熱＝0 的元素（要背）

  • 氫 H2(g)、溴 Br2(l)、碘 I2(s)、汞 Hg(l)　← 注意狀態
  • 有同素異形體時取含量最多或最穩定者：氧 O2(g)、碳 石墨 C(s)、磷 白磷 P4(s)、硫 斜方硫 S8(s)
觀念澄正 1：C(s)＋½O2(g)→CO(g) ΔH＝−110 kJ，可稱為 C 的莫耳燃燒熱
✗ 錯誤　這是不完全燃燒。要 C(s)＋O2(g)→CO2(g) 才是碳的莫耳燃燒熱。
觀念澄正 2：H2O(l) 的莫耳生成熱與 H2(g) 的莫耳燃燒熱為同值異號
✗ 錯誤　兩者其實是同一個反應 H2(g)＋½O2(g)→H2O(l)，所以是同值同號（都是 −285.8 kJ）。

重點三　赫斯定律（反應熱的加成性）

若一個反應式可由其他數個反應式組合而成，其反應熱亦等於這些反應熱的代數和。

特性：反應熱與途徑無關，只跟反應物的初始狀態與生成物的最終狀態有關。

路徑一：N2＋2O2→2NO2　ΔH＝+68 kJ
路徑二：① N2＋O2→2NO　ΔH1＝+180 kJ
　　　　② 2NO＋O2→2NO2　ΔH2＝−112 kJ
①＋②：ΔH1＋ΔH2 ＝ +68 kJ　✓ 相同

最常見用途：求不易測量的反應熱

碳不完全燃燒的反應熱無法直接測（一定會混到 CO2），用赫斯定律拆：

① C(s)＋O2→CO2　ΔH1＝−393.5 kJ
② CO＋½O2→CO2　ΔH2＝−283.0 kJ
②倒過來：CO2→CO＋½O2　ΔH2′＝+283.0 kJ
①＋②′：C(s)＋½O2→CO
ΔH ＝ −393.5＋283.0 ＝ −110.5 kJ

操作規則反應式相加減 → ΔH 跟著加減；反應式倒過來 ΔH 要變號、乘 n 倍 ΔH 也乘 n。

延伸公式（超好用）

ΔH ＝ Σ生成物的生成熱 − Σ反應物的生成熱
記法：ΔH ＝ 生生 − 反生

計算時記得：元素態的生成熱為 0（如 O2），可以直接不計。

最重要的一頁

溶解度規則（沉澱表）

每個離子都附中文名，看不懂符號也能背

先搞懂：溶解度的分級

難溶　< 10−4 M <　微溶　< 10−1 M <　可溶

「難溶」不是完全不溶，只是濃度低到會析出沉澱。微溶的那幾個最常被拿來出陷阱題。

① 全部可溶（碰到誰都溶）

離子中文規則
NO3−硝酸根遇所有離子皆可溶
CH3COO−醋酸根（乙酸根）
IA+鹼金屬
Li 鋰、Na 鈉、K 鉀、Rb 銣、Cs 銫
NH4+銨根

唯一例外CH3COOAg（醋酸銀）微溶。

為什麼重要做分離題時，試劑一定挑 NO3− 或 Na+ 當配角，就是因為它們絕不亂沉澱。

② 大部分可溶（只記難溶的例外）

Cl− 氯、Br− 溴、I− 碘（鹵離子）

遇下列離子難溶：

Hg22+亞汞（汞(I)）
Cu+亞銅（銅(I)）
Pb2+鉛
Ag+銀
Tl+亞鉈

注意價數名單裡的汞、銅、鉈全是低價態：Hg22+（亞汞）、Cu+（亞銅）、Tl+（亞鉈）。高價的 Hg2+（汞）、Cu2+（銅）、Tl3+（鉈）不在名單上，是可溶的。所以 CuCl 難溶、CuCl2 可溶。

陷阱是 Cu+（亞銅）難溶，不是 Cu2+（銅）。CuCl2 是可溶的。

SO42− 硫酸根

遇下列離子難溶：

Pb2+鉛難溶
Ca2+鈣微溶
Ag+銀微溶
Sr2+鍶難溶
Ba2+鋇難溶

注意Sr2+、Ba2+ 是 IIA 族中較重的兩個，Ca2+ 同族但只到微溶，Mg2+（鎂）則完全可溶 —— 同一族由上往下溶解度遞減。

CrO42− 鉻酸根

遇 Pb2+（鉛）、Ag+（銀）、Sr2+（鍶）、Ba2+（鋇）難溶。

跟硫酸根比幾乎一樣，差別是鉻酸根沒有鈣（CaCrO4 可溶）。

③ 大部分難溶（只記可溶的例外）

S2− 硫離子

遇 IA+（鹼金屬）、NH4+（銨根）、IIA2+（鹼土金屬：Mg 鎂、Ca 鈣、Sr 鍶、Ba 鋇）可溶，其餘難溶。

OH− 氫氧根

遇 IA+、NH4+、Ca2+（鈣，微溶）、Sr2+（鍶）、Ba2+（鋇） 可溶，其餘難溶。

跟 S2− 的差別氫氧根沒有鎂！Mg(OH)2 是難溶白色沉澱（胃藥「氫氧化鎂」就是懸濁液）。

CO32− 碳酸根、SO32− 亞硫酸根、PO43− 磷酸根

只有遇 IA+ 與 NH4+ 才可溶，其餘全部難溶。這三個最單純。

④ 微溶名單（四個，背起來）

CH3COOAg醋酸銀
CaSO4硫酸鈣
Ag2SO4硫酸銀
Ca(OH)2氫氧化鈣（石灰水）

四個全部都含 Ca2+（鈣） 或 Ag+（銀），其他陽離子不會出現在微溶名單裡。
