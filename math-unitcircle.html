用單位圓看 cos x = x/6π

拖動下面的滑桿，看那條垂直線怎麼移動
cos x（點的 x 座標）
1.000
x / 6π（紅線位置）
0.000
—
x = 0

紅線的位置怎麼算

紅線就是等號右邊那個值，直接把 x 代進去除以 6π 就好，沒有別的技巧。

x = 0　　→ 0 ÷ 6π = 0
x = 2π　→ 2π ÷ 6π = 1/3 ≈ 0.33
x = 4π　→ 4π ÷ 6π = 2/3 ≈ 0.67
x = 6π　→ 6π ÷ 6π = 1

所以每往右繞一圈（x 增加 2π），紅線就往右挪 1/3 格。繞三圈剛好挪到最右邊 x = 1，貼到圓的邊緣。

往左同理：x = −6π 時紅線在 −1，貼在圓的最左邊。

為什麼一圈通常有 2 個解

在單位圓上，cos x 就是那個點的 x 座標。要解 cos x = c，等於問「圓上哪些點的 x 座標等於 c」。

一條垂直線穿過圓，會交在上半圓一點、下半圓一點，所以每繞一圈得到 2 個角度 —— 這就是「一個週期 2 個解」的來源。

但是當 c = 1 或 c = −1 時，垂直線變成相切，只碰到 1 點。這就是端點特殊的地方。

那 13 個解是怎麼來的

老實說，上面那些小數（0.475π、1.585π…）是我用電腦掃出來的：把 −6π 到 6π 切成很多小段，看 cos x − x/6π 在哪裡由正變負或由負變正，變號的地方就夾著一個解，再二分逼近。

考試不需要算出這些數字，只要數「有幾個」。數的方法是看兩條曲線的上下關係換了幾次：

右側 x > 07 個（含端點 x = 6π 那個切點）
左側 x < 06 個
x = 0不是解（cos 0 = 1，但線在 0）
合計13 個

左右不一樣多，是因為直線是斜的：右邊終點 cos = 1、線也 = 1，剛好碰上；左邊終點 cos = 1 但線 = −1，差了整整 2 格，碰不到。
