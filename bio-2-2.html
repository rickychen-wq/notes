生物 · 2-2 營養器官

根、莖、葉的形態、構造與功能
2-2.1

根的形態與構造

吸收、固定、儲存，並連接地上部

一、功能與根系

根的主要工作

  • 吸收水與無機鹽
  • 支持、固定植物體
  • 儲存養分
  • 營養器官繁殖

變態根還可特化：榕樹氣生根吸收空氣水氣；海茄苳呼吸根露出泥面進行氣體交換；大萍水生根表皮薄；菟絲子寄生根伸入寄主吸收養分。

根系外部形態特性常見植物
軸根系初生根形成明顯主根，再長側根可深入土壤，水土保持佳裸子植物、雙子葉木本、多數雙子葉草本
鬚根系初生根萎縮，由莖基部長出許多不定根分布淺，能固定表土、減少沖蝕單子葉植物、少數雙子葉草本

二、根尖由前端往上

根帽 → 生長點 → 延長區 → 成熟區
部位細胞狀態主要功能
根帽位於最前端保護生長點，避免土壤摩擦損傷
生長點初生分生組織，持續有絲分裂增加根帽與延長區的細胞數
延長區細胞快速增大、伸長推動根向土中延伸
成熟區細胞完成分化，外有根毛吸收、運輸水與無機鹽
生長點靠分裂增加細胞數；延長區靠細胞增大使根伸長。成熟區不是主要分裂區。

三、成熟區橫切

由外往內

表皮 → 皮層 → 內皮 → 周鞘 → 中柱維管組織
  • 表皮：單層、排列緊密，通常沒有角質層；向外延伸形成根毛。
  • 皮層：多層薄壁細胞，負責儲存。
  • 內皮：皮層最內一層，卡氏帶可控制水與無機鹽進入中柱。
  • 周鞘：中柱最外層，可分裂形成側根。
比較雙子葉根單子葉根
木質部、韌皮部木質部在中央呈輻射狀，韌皮部位於其間環狀相間；木質部較內、韌皮部較外
形成層有，介於木質部與韌皮部無，根無法持續增粗
中央主要是木質部有薄壁細胞構成、可儲存的髓
根毛 ≠ 側根。根毛是成熟區單一表皮細胞的外凸；側根是周鞘細胞分裂形成的多細胞構造，內有維管束。
2-2.2

莖的形態與基本構造

先辨認節、節間、芽，再看維管束排列

一、功能與外部形態

莖的功能

  • 支持植物體
  • 運輸物質
  • 儲存養分
  • 營養器官繁殖

變態莖例：走莖延伸生長；塊莖、肉質莖、鱗莖可儲存養分；蓮、薑等根莖可繁殖，水生植物的根莖常具通氣構造。

構造定義與功能
節著生葉與芽的位置；芽內有分生組織
節間相鄰兩節之間
頂芽位在頂端，使莖持續生長
側芽位在節上，可長出新枝、葉或花

二、草質莖與木質莖

類型特性主要支持來源
草質莖柔軟、矮小細胞膨壓
木質莖堅硬、高大木質化厚壁細胞

木質莖可再分為：有明顯主幹的喬木、基部叢生且主幹不明顯的灌木、攀附其他物體的木質藤本。

三、草質莖橫切比較

比較單子葉草質莖雙子葉草質莖
維管束排列散生於基本組織，外多內少、外小內大環狀排列
形成層無，不能持續增粗有，但不發達，增粗有限
其他竹、水稻等常見髓腔中央有髓；髓射線連接髓與皮層，可橫向運輸
維管束內外木質部朝內，韌皮部朝外
葉脈也有木質部與韌皮部，但單、雙子葉植物的葉脈都沒有形成層。
2-2.2

木本莖與次級生長

形成層、樹皮、木材與年輪

一、單子葉木質莖

竹子、椰子等單子葉木質莖，維管束仍呈散生，通常沒有維管束形成層；細胞木質化後能強力支撐，但不能像雙子葉木本莖那樣持續次級生長。

外層雖會木質化，仍不能稱為樹皮；樹皮是雙子葉木本莖次級生長形成的構造。

二、雙子葉木質莖由外往內

木栓層 → 木栓形成層 → 栓皮層 → 皮層 → 韌皮部 → 維管束形成層 → 木質部 → 髓

兩種形成層

  • 木栓形成層：向外產生含木栓質、已死亡的木栓細胞；向內產生栓皮層。
  • 維管束形成層：向內產生次生木質部，向外產生次生韌皮部；產生的木質部通常較多。

木栓層、木栓形成層、栓皮層合稱周皮；木質部逐年累積形成木材。

三、木材與年輪

比較邊材心材
位置／形成外側、較晚形成內側、較早形成
顏色較淡較深
主要功能運輸支持
比較早材（春材）晚材（夏材）
環境與生長溫暖潮濕；生長快寒冷乾燥；生長慢
細胞較大、壁薄較小、壁厚
顏色較淡較深

生長季節差異明顯，且維管束形成層能持續分裂，才容易形成清楚年輪；一輪通常由同一生長年度的早材與晚材構成。

四、皮孔與氣孔

構造形成／控制位置與功能
氣孔兩個保衛細胞圍成，可開閉葉與幼嫩莖；氣體進出與蒸散
皮孔木栓層裂開，不能主動關閉木本莖樹皮；氣體進出
2-2.3

葉的形態與內部構造

葉序、葉形、葉脈與葉肉

一、功能與外部形態

葉的主要工作

葉片多扁平以接收光線，主要進行光合作用，也能儲存養分、營養繁殖或特化成捕蟲葉、攀附捲鬚、苞葉等。

比較單子葉植物雙子葉植物
葉脈平行脈網狀脈
與莖連接葉鞘葉柄
托葉通常無可有，保護葉芽

葉脈就是維管束，可分成主脈、側脈與細脈，負責運輸並支撐、固定葉片。

二、葉序與葉形

葉序同一節的葉片數
互生1 片
對生2 片
輪生多於 2 片

單葉與複葉怎麼分

  • 單葉：一個葉柄只連一片葉片，葉緣缺刻也仍是一片。
  • 複葉：一個葉柄有兩片以上小葉，各小葉基部彼此不相連。
判斷單位看側芽：真正葉柄基部可有側芽，小葉基部沒有側芽。三出、掌狀、羽狀都屬複葉。

三、葉片內部構造

由上往下

角質層 → 上表皮 → 柵狀組織 → 海綿組織 → 下表皮 → 角質層
構造細胞與排列主要功能
表皮單層扁平細胞，通常無葉綠體；外有蠟質角質層保護、減少水分散失
保衛細胞具有葉綠體，兩個圍成氣孔控制氣體進出與水分蒸散
柵狀組織近上表皮，長柱狀、排列緊密、葉綠體多主要進行光合作用
海綿組織近下表皮，不規則、排列疏鬆、間隙大促進氣體與水分交換
葉脈木質部在上、韌皮部在下運輸與支持；沒有形成層
一般表皮細胞通常沒有葉綠體，但保衛細胞有。柵狀與海綿組織合稱葉肉，都是薄壁細胞。
